# 📝 Formulário de Contato Responsivo

Um formulário de contato moderno, elegante e totalmente responsivo, construído para praticar e demonstrar o uso combinado de **CSS Grid** e **Flexbox** no alinhamento de componentes de interface (UI).
Esse 
---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e validação nativa de campos obrigatórios (`required`).
* **CSS3:** Estilização moderna utilizando gradientes lineares, sombras complexas (`box-shadow`, `drop-shadow`) e técnicas avançadas de layout:
  * **CSS Grid:** Utilizado para a estrutura macro do formulário (divisão de colunas para Nome/Sobrenome e Tipo de Consulta).
  * **Flexbox:** Utilizado para o alinhamento interno dos campos (Labels acima dos Inputs) e centralização do container na tela.

---

## 🎨 Demonstração Visual

### Layout Desktop
O formulário centralizado na tela com um fundo em gradiente moderno, trazendo campos organizados em duas colunas para otimização de espaço.

### Layout Mobile (Responsividade)
Graças às `@media queries`, ao atingir telas menores que `480px`, o layout em Grid se adapta automaticamente para uma única coluna, garantindo fluides em smartphones.
